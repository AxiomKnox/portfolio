Seam: content adapter Pages and shell (Navbar/Footer) import from src/content/adapter.ts, not src/data/*. Adapter re-exports profile-display + learning-signals. Islands still import some @/data/projects types/helpers today — deepen behind adapter when touching discovery.
Seam: discovery island ProjectsPageIsland owns URL sync + filter apply. ProjectsToolbar owns Search DSL UI and emits setState patches only — do not parse URL inside the toolbar.
Seam: architecture selection Keep diagram + accordion in one island sharing selectedId. ArchStep.id must equal ArchNode.id (arch() enforces for linear graphs).
Seam: learning signals LEARNING_SIGNALS_ENABLED is build-time only (astro env schema → learning-signals.ts). Content marks learning: true; showLearningSignal gates UI. Not a client toggle.
Seam: UI hybrid (ADR-0002) Starwind/Astro for static shell and About dialogs; shadcn React for toolbar, architecture accordion, ambient/motion/HeroGrid. Custom ThemeToggle; marked for prose (not Starwind Prose).
